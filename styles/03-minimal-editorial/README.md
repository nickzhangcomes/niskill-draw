# 极简编辑风

`minimal-editorial` · 极简线条 · 文生图

细线加少量亮色点缀，带一点杂志感。

## 适合什么

适合画单个物体、动物或抽象概念，强调留白和现代编辑感，输出干净克制。输入只需明确主体即可（一只什么 / 一个什么）。不适合复杂场景、多人物、热闹氛围。

**标签：** 物品 / 动物 / 概念 / 极简 / 高级感 / 插图 / 封面 / 留白 / 线稿 / 现代

## 提示词模板

```text
Minimal illustration of [SUBJECT], clean thin lines with selective vibrant color accents, lots of negative space, refined composition, modern editorial style, elegant and simple
```

## 槽位

- `[SUBJECT]`

把模板里的槽位换成你的内容即可。
