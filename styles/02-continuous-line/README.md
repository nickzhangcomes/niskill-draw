# 一笔画连续线条风

`continuous-line` · 极简线条 · 文生图

一根线不断，曲线更流动，有艺术感。

## 适合什么

适合画单一主体的一笔画风格连续线条插画，线条不断、流畅优雅，有手绘艺术感。特别适合人脸侧像、动物剪影、器物轮廓，用于品牌插画、生活方式海报、社媒配图、封面装饰。输入需要主体 + 线条颜色（如 black / dark blue / terracotta red）。与 minimal-lineart 的区别：minimal-lineart 是几何规整的多段线稿，本模板是一笔画艺术线条，曲线更流动更有表现力。不适合复杂多元素场景、需要填充色块或光影的画面。

**标签：** 物品 / 动物 / 人脸 / 侧脸 / 一笔画 / 连续线条 / 极简 / 线稿 / 艺术 / 流畅 / 品牌插画 / 海报 / 封面 / 咖啡馆 / 生活方式 / 留白 / 装饰

## 提示词模板

```text
A minimalist continuous line drawing of a [SUBJECT], illustrated in clean 2D flat vector style. Single continuous [LINE_COLOR] outline on a pure white background. No fills, no shadows, no textures, no unnecessary details. Simplified silhouette, smooth flowing curves, elegant proportions, modern abstract aesthetic, clean negative space, minimalist logo-inspired design.
```

## 槽位

- `[SUBJECT]`
- `[LINE_COLOR]`

把模板里的槽位换成你的内容即可。
